------------------------------------------------------------
CARA MENJALANKAN
------------------------------------------------------------
1. Klik 2x file "JalankanAplikasi.bat"
2. Aplikasi akan terbuka otomatis di Chrome kiosk mode
3. Untuk keluar: tutup Chrome, lalu tekan Ctrl+C di window CMD

------------------------------------------------------------
INSTALASI PERTAMA
------------------------------------------------------------
1. Saat pertama kali dijalankan, akan muncul halaman Installer
2. Klik "Saya Yakin, Install Sekarang"
3. Login admin:
   Username: admin
   Password: admin123
4. SEGERA ubah password di menu "Ubah Password"
5. Isi identitas instansi di menu "Pengaturan"
6. Setup kamera di menu "Cek Kamera"

------------------------------------------------------------
TRIAL 14 HARI
------------------------------------------------------------
Aplikasi ini berjalan dalam mode TRIAL selama 14 hari.
Setelah 14 hari, Anda perlu melakukan aktivasi.

Cara aktivasi:
1. Buka aplikasi, akan muncul halaman aktivasi
2. Copy "Computer ID" (64 karakter)
3. Kirim Computer ID ke vendor via WA/email
4. Vendor akan mengirim kode aktivasi (GRT-XXXX-XXXX-XXXX-XXXX)
5. Masukkan kode + nama instansi, klik "Aktivasi Sekarang"

------------------------------------------------------------
BACKUP DATA
------------------------------------------------------------
- Buka menu "💾 Backup" di admin
- Klik "Backup Sekarang"
- File backup tersimpan di folder "_backup\"
- Disarankan backup rutin (minimal 1x seminggu)
